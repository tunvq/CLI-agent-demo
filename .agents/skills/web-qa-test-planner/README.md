## 📚 Skill Knowledge Base

### Phase 1: Exploration
**When to Use:** Start of any web app testing  
**Location:** SKILL.md Phase 1  
**Time:** 20-30 minutes  

Steps:
1. Open application with Playwright CLI
2. Test create/add functionality
3. Test read/view functionality
4. Test update/edit functionality
5. Test delete functionality
6. Test filtering and views
7. Test bulk operations
8. Verify data persistence

### Phase 2: Test Plan
**When to Use:** After exploration complete  
**Location:** SKILL.md Phase 2  
**Time:** 30-40 minutes  

Deliverables:
1. Main test plan (20-30 test cases)
2. Execution report (results & metrics)
3. Automation guide (Playwright code)
4. Summary document (executive overview)
5. Deliverables index (navigation)

### Phase 3: Automation
**When to Use:** For continuous testing  
**Location:** SKILL.md Phase 3  
**Time:** 10-15 minutes  

Includes:
- Copy-paste Playwright code
- File organization
- CI/CD examples
- Performance benchmarks
